## Почему Local Knights ♟️

- Полностью бесплатная программа с открытым исходным кодом под лицензией MPL-2.0. Без подписок и рекламы
- Полностью локальное настольное приложение без зависимости от облачных сервисов. Понятная навигация, адаптивная компоновка, светлая и тёмная темы и поддержка нескольких языков
- Данные клуба хранятся в одном защищённом паролем файле базы данных. Все данные легко копировать и восстанавливать
- Отлично подходит общественным шахматным клубам, дружеским компаниям и школьным программам, которым нужно нечто более структурированное, чем электронные таблицы, но с бесплатным и открытым рабочим процессом

## Основные возможности 🚀

### Управление участниками клуба 👥

- Регистрируйте игроков и ведите полные профили участников клуба
- Связывайте профили игроков с [Chess.com](https://www.chess.com/), [Lichess](https://lichess.org/), [FIDE](https://www.fide.com/) и другими шахматными организациями
- При создании игрока вводите рейтинг вручную или получайте его с поддерживаемых внешних платформ
- Ведите отдельные рейтинги участников для разных контролей времени (Bullet, Blitz, Rapid и Classical)

### Проведение соревнований 🏆

- Поддержка рейтинговых систем [Glicko-2](https://en.wikipedia.org/wiki/Glicko_rating_system#Glicko-2_algorithm) и [Elo](https://en.wikipedia.org/wiki/Elo_rating_system). Обновляйте рейтинги при записи партий и результатов турниров
- Записывайте отдельные партии (рейтинговые или нерейтинговые) и при необходимости сохраняйте их нотацию [PNG](https://en.wikipedia.org/wiki/Portable_Game_Notation)
- Проводите турниры по [швейцарской системе](https://en.wikipedia.org/wiki/Swiss-system_tournament), [круговые турниры](https://en.wikipedia.org/wiki/Round-robin_tournament), турниры [на выбывание](https://en.wikipedia.org/wiki/Single-elimination_tournament) и матчи между двумя игроками. Управляйте турами, парами, таблицами и результатами в одном месте
- Составляйте пары по швейцарской системе согласно утверждённой ФИДЕ логике с помощью библиотеки [Chesspairing](https://github.com/gnutterts/chesspairing/)
- Экспортируйте турниры в удобном формате Excel или официальном формате TRF ФИДЕ

### Современное настольное приложение 💻

- Создано с использованием современных технологий и адаптивных экранов, удобных при разных размерах окна
- Предназначено для повседневной работы и предлагает понятную навигацию по игрокам, партиям, турнирам и настройкам клуба
- Светлая и тёмная темы для разных условий и предпочтений
- Поддержка локализации на разные языки

### Локальный контроль данных 🔒

В отличие от клубных веб-инструментов, Local Knights обеспечивает полный локальный контроль.

- База данных клуба находится на вашем компьютере. Внешний сервер не требуется
- Для резервного копирования достаточно скопировать один зашифрованный файл `.db`
- Восстановление выполняется просто, переносимо и не зависит от сторонней инфраструктуры

## Начало работы ▶️

Создать и запустить клуб намеренно просто.

1. Скачайте последнюю версию приложения в виде ZIP-файла со страницы [релизов](https://github.com/urbanoanderson/local-knights/releases).
1. Распакуйте содержимое архива в любую удобную папку. При желании создайте ярлык для исполняемого файла «Local Knights.exe».
1. Запустите приложение с помощью «Local Knights.exe».
1. При первом запуске нажмите кнопку «+» и укажите название клуба, настройки рейтинга, пароль и другие параметры.
1. Войдите в клуб с созданным паролем и откройте панель управления.
1. Регистрируйте игроков по одному кнопкой «Создать» на странице игроков. Также поддерживается массовый импорт файлов игроков в формате CSV ([пример файла импорта](Scripts/Seed/player-bulk-import-sample.csv)).
1. Создавайте партии и турниры с зарегистрированными игроками на соответствующих страницах и в формах создания.
1. Наслаждайтесь игрой и поддерживайте шахматную жизнь в своём сообществе! Данные клуба будут храниться в «C:\Users\<USERNAME>\AppData\Local\LocalKnights\Clubs».

## Конфиденциальность и обработка данных ⚠️

Это приложение разработано с учётом конфиденциальности:

- **Только локальное хранение**
  Все данные клуба (игроки, партии и турниры) хранятся локально на компьютере пользователя в базе данных SQLite. Приложение не передаёт, не синхронизирует и не предоставляет данные внешним серверам или третьим лицам.

- **Разработчик не собирает данные**
  Разработчик этого программного обеспечения не собирает, не просматривает и не обрабатывает личные сведения, введённые в приложение.

- **Ответственность руководителей клуба**
  Руководители и администраторы клубов, использующие это программное обеспечение, отвечают за соблюдение применимого законодательства о защите данных, включая Общий регламент ЕС по защите данных (GDPR) и бразильский закон Lei Geral de Proteção de Dados (LGPD). Это предполагает информирование игроков об использовании их данных, получение согласия при необходимости и соблюдение прав на доступ, исправление и удаление.

- **Рекомендации по безопасности**
  - Защитите доступ к компьютеру и файлам базы данных.
  - Регулярно и безопасно создавайте резервные копии данных.
  - Используйте надёжные пароли для защиты настоящих баз данных клуба. Local Knights и сторонние сервисы не создают резервных копий паролей. Чтобы не потерять доступ к данным клуба, рекомендуется использовать менеджер паролей.

**Отказ от ответственности:** Это программное обеспечение предоставляется «как есть». Оно упрощает локальное управление данными, однако вся ответственность за законное использование персональных данных и соблюдение требований лежит на руководителях и администраторах клуба.

## Информация для разработчиков 🛠️

### Используемые технологии ⚙️

- Настольное приложение .NET 10 на основе WPF и шаблона MVVM
- Хранилище SQLite с SQLCipher для защиты паролем
- Библиотека [Chesspairing](https://github.com/gnutterts/chesspairing/) для составления пар по правилам ФИДЕ

### Версионирование 🔢

- Local Knights использует формат версий `MAJOR.MINOR.REVISION`
- Стабильные релизы основаны на ветке `main`. Экспериментальные предварительные версии основаны на ветке `dev`
- Процессы CI/CD автоматически выполняют сборку и тестирование, создают артефакты и выпускают предварительные и окончательные версии

### Сборка, тестирование и запуск из исходного кода 🧪

Требуется .NET 10 SDK

```bash
dotnet restore

dotnet build ProjectSolution.slnx

dotnet test ProjectSolution.slnx

dotnet run --project LocalKnights.WindowsDesktop/LocalKnights.WindowsDesktop.csproj
```

### Создание пакета Microsoft Store 📦

В Windows с установленными .NET 10 SDK и Windows SDK выполните:

```powershell
.\Scripts\create-msix.ps1
```

Команда создаёт неподписанный пакет MSIX x64 по адресу
`LocalKnights.WindowsDesktop\bin\Packages\LocalKnights_<version>_x64.msix`, используя
удостоверение пакета, связанное с Local Knights в Partner Center. Загрузите этот файл
в раздел **Пакеты** отправки; Microsoft Store подпишет его после отправки.
Перед отправкой обновления увеличьте версию проекта.
